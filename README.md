# La Mujer con Chalina — V2

Segunda versión independiente del prototipo. Este repositorio parte de la estructura narrativa de V1, pero se desarrolla y publica por separado para no modificar el enlace utilizado en la primera evaluación.

## Objetivo de V2

Explorar una etapa de creación narrativa personalizada: a partir de la información que la persona comparte sobre un recuerdo de alguien fallecido, el sistema preparará un texto emotivo que conecte los detalles concretos de la historia.

## Criterios para el texto narrativo

- Utilizar únicamente hechos y detalles proporcionados o confirmados por la persona.
- No inventar diálogos, pensamientos, emociones ni acontecimientos.
- Se permiten recursos literarios y metáforas que no alteren los hechos.
- Mantener un tono cálido, respetuoso y no terapéutico.
- Permitir revisar, corregir o descartar el texto antes de conservarlo.
- No imitar ni simular la voz de la persona fallecida.

## Estado técnico

- Este repositorio es independiente de V1.
- El prototipo inicial es una base de interfaz estática.
- La generación con un modelo de IA real todavía requiere diseñar e integrar un backend seguro; no se deben exponer claves de API en el navegador.
- El formulario de evaluación de V2 está pendiente de configuración. El enlace de evaluación de V1 no se reutiliza aquí.

## Publicación

El archivo de entrada es `index.html`. Para desplegarlo, conecta este repositorio como un proyecto nuevo en Vercel o configura GitHub Pages de forma independiente.

## Versionado

- **V1:** primera versión de evaluación; no modificar desde este repositorio.
- **V2:** línea de desarrollo independiente para incorporar texto narrativo personalizado.
